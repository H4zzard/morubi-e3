# Morubi + E3 Digital

Apresentação estratégica em HTML, CSS e JavaScript puro.

## Como abrir

Abra `index.html` em um navegador moderno. A apresentação funciona sem servidor e sem dependências externas.

## Controles

- Próximo slide: seta direita, espaço ou Page Down
- Slide anterior: seta esquerda ou Page Up
- Primeiro slide: Home
- Último slide: End
- Celular e tablet: deslize horizontalmente

O layout se adapta automaticamente a desktop, notebook, tablet e celular. Cada slide cabe integralmente no viewport em zoom 100%, sem rolagem interna, e a navegação ocupa uma faixa própria no rodapé.
